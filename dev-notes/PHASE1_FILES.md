# Phase 1 files

Copy the contents of this bundle into the matching paths in your existing `iq-signal-classifier` repository. It intentionally does not replace your starter scaffold or project configuration.

Included files:
- `src/iq_signal_classifier/__init__.py`
- `src/iq_signal_classifier/signal_gen.py`
- `tests/test_signal_gen.py`
- `scripts/plot_examples.py`

Phase 1 dependencies: NumPy and Matplotlib. Pytest is required to run tests. Do not pin the entire project's ML stack until the PyTorch, NumPy, scikit-learn, and Matplotlib combination has been confirmed together in a later phase.
